# AI 禁飞区

课程规定以下三个核心功能必须由学生手写。AI 只可帮助澄清概念、审查最终代码或提出
测试思路，不得生成实现代码、可直接翻译的伪代码或补全核心算法。

## 1. 简历多维度权重计算

范围：

- 评分维度、权重和归一化；
- 单项得分与扣分规则；
- 缺失数据和边界值处理；
- 总分合成及评分版本管理。

AI 可以做：解析简历字段、生成解释文案。

AI 不可以做：输出评分函数、权重计算代码或替学生决定最终分数。

验收证据：

- 人工设计稿；
- 评分公式说明；
- 边界值单元测试；
- 作者逐行讲解记录。

## 2. 岗位匹配相似度排序

范围：

- 技能和条件归一化；
- 必备项、加分项、经验等分项匹配；
- 相似度计算和加权；
- 排序、并列和缺失条件规则。

AI 可以做：从 JD 和简历中抽取候选结构化标签。

AI 不可以做：生成最终相似度、排序函数或直接用模型主观分数替代算法。

验收证据：

- 匹配特征表；
- 算法说明；
- 固定简历/JD 排名样例；
- 排序不变量和边界测试。

## 3. 模拟面试对话状态机

范围：

- 状态集合；
- 状态转换表；
- 追问、下一题、超时、重试和结束条件；
- 会话状态持久化与恢复。

AI 可以做：按当前状态生成问题、追问和评价内容。

AI 不可以做：决定状态转换、控制面试是否结束或生成状态机实现。

建议状态：

READY → ASKING → WAITING_ANSWER → EVALUATING
     → FOLLOW_UP / NEXT_QUESTION → SUMMARIZING → COMPLETED

Sprint 2 最小版先采用固定 3 题流程：

READY → ASKING → WAITING_ANSWER → EVALUATING
      → NEXT_QUESTION → ASKING → WAITING_ANSWER → EVALUATING
      → NEXT_QUESTION → ASKING → WAITING_ANSWER → EVALUATING
      → SUMMARIZING → COMPLETED

异常状态：FAILED、CANCELLED。

Sprint 2 约束：

- AI 可以生成面试问题、回答评价和总结建议。
- AI 不得决定状态转换、当前题号、结束条件、最大题数或重试次数。
- AI 不得生成状态机实现代码或可直接翻译为代码的状态转换伪代码。
- 状态机实现必须由成员人工编写，并由 QA 覆盖非法转换测试。

验收证据：

- 人工状态图和转换表；
- 非法转换测试；
- 最大追问次数测试；
- 中断恢复与结束条件测试。

## 4. 代码管理

- 禁飞区代码使用清晰的模块目录，不与 AI 生成代码混放。
- Commit 正文标记 `No-Fly-Zone` 和人工作者。
- 开发 AI 日志必须证明 AI 未生成禁飞区代码。
- 禁飞区变更必须由作者和 QA 双人 Review。
- 验收前每位作者独立完成一次白板讲解和一次无 AI 修改演练。
