## 根因与修复

- **根因 1（适应只贴竖直）**：原实现用 CSS `transform:scale` 缩放，且适应逻辑误以为只处理了高度方向。
- **根因 2（放大后丢图）**：`transform:scale` 不改变布局尺寸，滚动区仍是未缩放尺寸，放大后内容缩在左上角、滚动到空白处就"看不见图"。
- **修复**：舞台（stage）尺寸改为**实际渲染尺寸 = 基础尺寸 × 缩放比**（iframe/img 填满舞台），滚动区与页面一致；"适应"改为同时取宽/高比例较小者（both-dimension fit）；PDF 与图片共用同一套查看器（− / 百分比 / ＋ / 适应 + 拖拽平移 + Ctrl+滚轮）。

## 实测

- PDF：打开自动适应 66%（舞台 524×741 = 视口 530×741，宽高同时适配、无横向溢出）；放大 116% 时舞台 921px、滚动区 921px（正确可滚可拖）。
- 图片：真实 640×400 PNG 自动适应 83%（按宽度约束），放大后滚动区正确、不丢图。
