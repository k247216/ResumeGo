## 真实用户流程

1. 知识库顶部新增紧凑搜索条：搜索框 + 分类/标签下拉筛选（数据来自后端 catalog）。
2. 输入关键词即搜索（标题+正文），左栏切换为真实搜索结果：标题、命中字段（标题命中/正文命中）、≤240 snippet、正文命中行号；清空关键词回到文档列表（空 query 不请求）。
3. 右侧详情下方新增分类/标签面板：分类下拉（含“无分类”）、已选标签展示可移除、未选标签可从下拉添加；可新建分类/标签（轻量弹窗）。
4. 关联写入成功后重新读取服务端状态回显；失败保留旧值并局部报错，绝不乐观伪造。

## 乱序/错误恢复策略

- store 用递增 `searchRequestSequence`：每次 setSearchQuery/setSearchFilter/clearSearch 递增；搜索响应返回时比对序号，过期响应直接丢弃（不覆盖结果或错误）。
- 空 query 清空结果且不调用 API；filter 指向已失效（不在 catalog）的 id 时清空该 filter 而不是发请求。
- 搜索失败只写 searchErrorMessage（左栏局部重试），不清空 documents；关联失败保留旧 classification 并写 classificationErrorMessage。

## Client 实现要点

- 统一复用 parseResponse + KnowledgeHttpError；无手动拼 URL（路径模板 + URLSearchParams）。
- 保留 FE-00 documents/import/content 行为；未新增 open-source/retry/delete API。
