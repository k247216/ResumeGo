## 端点行为

- `GET/POST /api/v2/knowledge/categories`、`GET/POST /api/v2/knowledge/tags`：名称 trim + 合并内部空白、1–40；normalized 用 Locale.ROOT 小写；重复 normalized 返回既有记录（200），新建 201；空名 400。
- `PUT/DELETE /api/v2/knowledge/documents/{documentId}/category/{categoryId}`：每文档一个分类，重复设置即替换；关联/解除不存在或外部用户的 document/category 一律 404（不泄露所有权）。
- `PUT/DELETE /api/v2/knowledge/documents/{documentId}/tags/{tagId}`：多对多，重复关联幂等（唯一约束兜底）。
- `GET /api/v2/knowledge/search?q=&categoryId=&tagId=`：
  - q trim 1–100，字面子串匹配，SQL wildcard（% _ \）全部转义 + ESCAPE '\'；LOWER() 中英文大小写不敏感。
  - 标题对所有文档可命中；正文仅 COMPLETED 的 extracted content 参与（LEFT JOIN 限定 processing_status），PENDING/RUNNING/FAILED 不伪造正文命中。
  - 可选 filter 必须属于当前用户（EXISTS 内带 user_id），外部 filter 404；无结果空数组。
  - 排序 updated_at DESC, id DESC，LIMIT 100。
  - 结果含 document 元数据 + matchedField(TITLE|CONTENT) + ≤240 字 snippet（命中位置为中心，前后省略号）+ 正文命中时 1-based lineNumber（标题命中为 null）；不返回全文/路径/hash。
