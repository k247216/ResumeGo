## IPC / 内部端点契约

- Renderer 只向 preload 传正整数 `documentId` + 固定动作 `open|reveal`；preload 暴露 `openKnowledgeSource(documentId)` / `revealKnowledgeSource(documentId)`，只返回 `{ok:true}` 或 `{ok:false, code, message}`，不含本地路径/hash/正文/internal token。
- Electron main 用 workspace token + 仅 main 持有的 `X-ResumeGo-Internal` 调用 `GET /api/v2/internal/knowledge/documents/{id}/managed-source`（恒定时间校验，renderer 无法直接调用）。
- 后端稳定失败：`SOURCE_NOT_FOUND`（缺失/跨用户统一）/ `SOURCE_NOT_FILE` / `SOURCE_NOT_AVAILABLE` / `SOURCE_MISSING`。

## 路径校验边界

- `resolveManagedSourcePath` 纯函数：相对路径 `resolve` 到 dataDir 后必须落在 `knowledge/sources/` 根内（拒绝 ../、绝对路径、sources 外）；`stat` 必须是普通文件（拒绝目录）；`realpath` 后真实路径仍须在 real 根内（拒绝符号链接逃逸）。
- open 用 `shell.openPath`、reveal 用 `shell.showItemInFolder`；系统错误归一化为 `OPEN_FAILED`/稳定 message，响应与普通日志均不包含本地路径（测试断言 JSON 无 dataDir）。
