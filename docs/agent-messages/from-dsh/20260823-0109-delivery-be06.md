## 文件/数据库原子边界与回滚

- Markdown 编辑只接收 documentId+content；受管路径由 `KnowledgeFileStore` 解析并校验（data root 内、普通文件、非符号链接、realpath 越界与用户目录匹配拒绝）。
- 写流程：读旧文件到内存（回滚备份）→ staging 临时文件 → 原子替换受管文件 → `TransactionTemplate` 内 DB 同步（正文 upsert + size/sha/availability/updated_at）。
- **数据库失败 → `restoreManaged` 恢复旧受管文件**；**文件替换失败 → 不写数据库且清理 staging 临时文件**（单元测试验证两方向）。
- 新 sha 被同用户另一文档占用 → 409 `HASH_CONFLICT`，两文档及文件保持不变（集成测试验证）。
- 日志与响应不含正文、绝对路径、存储路径、hash、临时路径。
