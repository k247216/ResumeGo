## 循环/深度算法

- 最大深度五级：根 depth=0，最深 depth 4；创建时校验 parentDepth+1 ≤ 4。
- 移动（PUT）校验：parent 属于当前用户（404）；不能是自身；不能是自身后代（沿 parent 链上溯 isAncestor）；移动后 parentDepth + 1 + subtreeHeight(原节点) ≤ 4。
- 所有校验在读+写同一 @Transactional 内完成；失败不写入，事务不留下半移动（集成测试断言失败后深度不变）。
- computeDepths 用 BFS（根=0），孤儿防御在 BFS 之后；descendantDocumentCount 后序记忆化 = 直属 + 各子节点子树文档总数（口径：含自身子树）。

## 计数口径

- directDocumentCount = knowledge_document_categories 按 category_id 的真实 COUNT（每文档一个分类）。
- descendantDocumentCount = 该节点及其全部后代分类的直属文档总数（真实关联在内存聚合）。

## 端点行为

- `POST /api/v2/knowledge/categories`：`{name, parentId?}`；旧 `{name}` 等价根节点；重复 normalized 返回既有（200）/新建 201；跨用户 parent 404；超五级 400。
- `PUT /api/v2/knowledge/categories/{id}`：`{name, parentId}` 两字段显式（parentId 可 null 移到根）；循环/深度/重名拒绝。
- `DELETE /api/v2/knowledge/categories/{id}`：仅空叶（无子分类且无直属文档），否则 409 `CATEGORY_NOT_EMPTY`；不 cascade、不静默移动文档。
- `GET /api/v2/knowledge/categories`：扁平节点 `id/name/normalizedName/parentId/depth/directDocumentCount/descendantDocumentCount/createdAt/updatedAt`，前端构树。
- `GET /api/v2/knowledge/search`：新增 `includeDescendants`（仅 categoryId 非空生效）；true 匹配该分类+全部后代分类的直属文档（IN 子查询），false 仅直属；标签筛选可叠加。
