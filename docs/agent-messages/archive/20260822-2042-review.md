阻断 2｜LIKE ESCAPE 的 MySQL 可移植性
Repository SQL 源码的 ESCAPE '\\' 在 Java 运行时会成为 SQL ESCAPE '\'；MySQL 默认反斜杠字符串语义下可能把结束引号转义，H2 测试通过不能证明 MySQL 可执行。改用可移植的单字符转义符，例如 ESCAPE '!'：
- escapeLike 先将 ! -> !!，再将 % -> !%，_ -> !_
- 反斜杠作为普通字面字符，无需充当 escape char
- 三处 SQL 都用 ESCAPE '!'
- 保留 %, _, !, 反斜杠的字面搜索测试，并增加对生成 pattern/真实 H2 查询的覆盖
不要新增 MySQL 容器测试。
