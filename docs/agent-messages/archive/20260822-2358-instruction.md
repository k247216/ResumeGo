# 知识库界面最终验收基线：目标图一致性修正
- From: Codex
- Type: instruction
- Related task: V2-F2-FE-02
- Date: 2026-08-22T15:58:02.873Z
用户已明确批准，以下要求覆盖此前零散视觉意见，作为 FE-02 最终界面验收基线。不得扩展新业务，不得伪造后端尚未支持的数据。

一、左侧全局工具栏
- 工作台、求职目标、简历、知识库、模拟面试、日程均使用与目标图一致语义的真实小图标；统一尺寸、线条和间距。
- Knowledge 当前态清晰但克制；保持窄栏桌面工具感，不做网页菜单。
- 不使用文本符号或 emoji 充当图标，统一用项目现有 Element Plus icons。

二、顶部命令区
- 更接近 docs/design/v2-knowledge-library-target.png 的比例、留白和排列。
- 搜索居中；黑色主按钮“导入资料”；白色次按钮“新建笔记”。
- 不增加 AI 状态、统计和欢迎语。

三、资料库导航
- 多级文件夹真实展开/收起、缩进和计数；标签在树下方。
- 弱分隔，不用卡片式边框；文件夹/标签操作使用真实小图标。
- 不自动写入示例分类。

四、全部资料列表（最高优先级）
- 文件类型必须一眼可辨，不得使用统一普通文件图标。
- 当前只显示真实支持类型：NOTE、Markdown、TXT；图标/类型文案必须来自真实 sourceType/extension。
- 后续 PDF/DOCX/PPTX 支持后再自动增加，本阶段不得伪造。
- 每行：真实类型图标、标题、所属文件夹完整路径或主要标签、更新时间、真实处理状态。
- 连续行 + 轻分隔，不做独立卡片。
- 列表头至少实现真实“按更新时间”排序和明确收起；单一视图时不做假视图菜单。
- 收起/恢复不改变当前文档选择。

五、正文阅读区（视觉主体）
- Markdown 渲染为标题、段落、列表、代码块，不直接展示 #/##/- 原始符号。
- 必须安全：禁用 raw HTML/XSS；NOTE 编辑仍编辑原始 Markdown，保存后回到阅读态；FILE 只读。
- 正文应是最宽区域，控制行宽、行距、段落间距；关闭列表/检查器后自然扩展。
- 标题区只保留标题、来源状态、更新时间和 inspector 入口；入口使用真实 icon + 可访问名称。

六、右侧来源与属性
- 做成窄工具条，不抢正文：宽屏约 260–280px；中等窗口使用右侧 overlay。
- 分类展示完整路径，例如“技术知识 / 系统设计”，选择项也必须可区分父子。
- 保留标签、本地来源、打开原文、文件夹定位、真实删除。
- 资产关系/相关资料接口未实现时隐藏，禁止写死。
- 减弱危险区域视觉面积，保持可发现即可。

七、整体视觉
- 同一桌面画布，弱化四块拼接和强边框；主要靠间距、对齐、字号与低对比分隔线。
- 黑白主调；仅文件类型、状态使用克制功能色。
- 保持目标图的信息密度与呼吸感，不因留白丢失文件信息。

八、响应式（严格）
- ≥1320：导航 + 列表 + 正文 + 窄 inspector 同时显示。
- 1160–1319：inspector 默认关闭，打开为右侧 overlay。
- 1080–1159：navigator 收起到 44px；list 约300px；inspector overlay。
- 正文有效最小宽约460px；不得横向滚动或变移动端卡片流。
- 修正当前 1280×720 四栏并排导致正文约290px、标题三行断裂的问题。

九、交互与焦点
- Ctrl/Cmd+K 搜索；方向键移动资料、Enter 打开；Esc 关闭 inspector/对话框。
- 收起区域后焦点转到恢复按钮；对话框关闭后返回触发控件。
- 文档间保存、分类和来源错误严格隔离。

验收证据：
1) 目标图与同状态实现截图并排；
2) 1280×720 与 1080×720 截图；
3) NOTE + MD/TXT 真实类型列表；
4) 文件夹过滤、列表收起、inspector overlay/关闭、Markdown 阅读态；
5) 仅必要定向测试，不扩大测试矩阵。

完成后提交单一 UI 修正 commit + 交付报告。
