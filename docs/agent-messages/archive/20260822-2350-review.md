但与已冻结的 docs/design/v2-knowledge-library-target.png 和 interaction-design.md 仍有 5 个核心差异，暂不集成。只修这些，不扩展业务：

P0-1 响应式严格对齐冻结契约：
- 目前 applyResponsive 仅 <1160 关闭 inspector、<1080 收起 list，且从不收起 navigator。
- 实测 1280×720 四栏并排，正文只剩约 290px，标题三行断裂。
- 应为 ≥1320 四栏；1160–1319 默认关闭 inspector（重新打开用右侧 overlay）；1080–1159 navigator 收起为 44px、list 保持约300px、inspector overlay。
- 不产生横向滚动，正文最小宽度 460px。

P0-2 正文必须是 Markdown 阅读样式：
当前直接 <pre> 显示 #、##、- 原始语法，目标图和契约要求渲染后的标题、段落、列表；NOTE 编辑仍保留原始文本，FILE 只读。使用项目已有安全 Markdown 能力；若无依赖，采用明确安全的轻量解析，不允许 raw HTML/XSS。补标题/列表渲染测试。

P0-3 命令区主次对齐：
冻结图和规范为黑色主按钮“导入资料”、次按钮“新建笔记”；当前完全相反（新建笔记黑色）。改回目标，不改功能。

P1-1 资料列表头补齐契约：
至少提供真实“按更新时间”排序和明确收起按钮；视图菜单如当前只有单一视图可先隐藏，不做假菜单。每行次信息应显示真实所属文件夹路径或最相关标签 + 更新时间，而不是只有“笔记 · 日期”。文件类型仅显示真实 NOTE/MD/TXT，不得伪造 PDF/DOCX/PPTX。

P1-2 右侧分类显示层级路径：
嵌套分类当前只显示“系统设计”，目标应显示“技术知识 / 系统设计”；选择项也应可辨识父子路径。资产关系/相关资料后端未实现时继续隐藏，这一点当前正确，不要写死。

同时修掉可见的文本符号图标“⚙ 来源与属性”，改用已有 Element Plus 图标；保持可访问名称。键盘方向/Enter/Esc/收起后焦点恢复列入紧接的 UX-02 卡，不阻塞本次视觉集成。
