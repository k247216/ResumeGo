用户结果：用户能建立个人分类与标签，并从标题或已完成提取的正文中查到真实片段；结果提供匹配字段、短 snippet 与正文行号，不返回全文。

冻结数据：
- H2 V8 + MySQL V28 等价迁移。
- knowledge_categories / knowledge_tags 均带 user_id、name、normalized_name、timestamps；同用户 normalized_name 唯一。
- knowledge_document_categories 每文档最多一个分类。
- knowledge_document_tags 多对多、重复关联幂等。
- 名称 trim + 合并内部空白，1–40；Locale.ROOT 小写归一化；禁止跨用户合并。

冻结 API：
- GET/POST /api/v2/knowledge/categories
- GET/POST /api/v2/knowledge/tags
- PUT/DELETE /api/v2/knowledge/documents/{documentId}/category/{categoryId}
- PUT/DELETE /api/v2/knowledge/documents/{documentId}/tags/{tagId}
- GET /api/v2/knowledge/search?q=&categoryId=&tagId=
- 重复 normalized 名称返回既有记录。
- 外部用户或不存在资源统一 404。
- q trim 1–100，字面子串匹配，必须转义 SQL %, _ 和反斜杠；中文和英文大小写不敏感。
- 所有文档可标题命中；正文只检索 COMPLETED extracted content。
- optional filters 必须属于当前用户。
- updated_at DESC,id DESC，最多 100。
- result 含 document metadata、matchedField TITLE|CONTENT、<=240 snippet、正文 1-based lineNumber；无全文/路径/hash。
