# 真实面经资料格式

“真实面经”是知识库中的普通分类，不是另一套题库。将资料归入该分类后，真题演练会读取已完成提取的正文；只有用户在真题演练中选择资料时，才会创建一个带 `source_document_id` 的本地题集。

## 推荐格式

```markdown
---
company: 腾讯
role: Java 后端
icon: tencent
---

1. 讲讲 Redis 缓存一致性
2. 如何排查慢查询？
3. 介绍一个你处理高并发的项目
```

### 元数据

- `company` 或 `companyName`：可选，公司名称；只用于展示和本地 Logo 匹配。
- `role` 或 `targetRole`：可选，应聘岗位。
- `icon` 或 `companyIconKey`：可选，本地品牌资源标识，例如 `tencent`。
- 未填写或未收录的公司不会被猜测，界面显示首字母标识。

### 题目

每道题必须单独一行，并使用下列任一种前缀：

- `1. 题目`
- `1) 题目`
- `1、题目`
- `- 题目`
- `* 题目`

导入 Markdown、TXT 或可提取文本的 PDF 后，系统不会改写原文件，只会把提取正文按同一规则解析。解析成功会显示题目数量；没有明确题目时会显示格式错误，不会让 AI 补写“真实面经”。

## 与真题演练的关系

选择资料后创建的题集保留 `source_document_id`，作为真题演练中的稳定入口。题集尚未归档时，重新打开真题演练或读取题集详情会以知识库当前正文和 front matter 同步题目、公司、岗位与 Logo；已经开始的面试使用开始时的快照，不会被后续编辑改写。资料暂时无法解析时保留上次可用题集，并在知识库中显示格式问题。

## 时间与来源

资料列表显示知识文档的创建/更新时间。真实面试发生的日期、时间和会议链接属于求职管线/日程，不从文件更新时间推断，也不会写入面经题集快照。
