# 职达 Career OS V2.0

职达 Career OS V2.0 是一套本地优先的个人职业资产工作台。它把知识资料、求职计划、简历版本、面试训练和复盘反馈串成一条可持续的准备流程，让用户每天都能从真实数据出发完成下一步行动。

## 这一版解决什么问题

- 用多个独立的求职计划管理公司、岗位、JD、阶段、简历版本、面试和日程，不再把不同机会混成一条记录。
- 用知识库沉淀 Markdown、PDF、TXT 和真实面经资料，支持目录、标签、搜索、预览以及受管笔记编辑。
- 用基础简历和岗位表达版本分离的方式，让版本可以复制、对比、归档和恢复，不会因为切换岗位而悄悄覆盖另一份简历。
- 用三种来源清晰的面试模式完成训练：岗位自由面试、基于知识库的知识训练、基于真实题集的真题演练。
- 在面试开始时保存岗位、简历、资料或题集的上下文快照，结束后进入复盘，把核心问题转成下一步可执行的准备行动。
- 用 Workspace 首页聚合下一场真实面试、当前目标、关联简历、最近活动和直达工具，而不是把所有功能堆在 Dashboard 上。

## 已交付能力

- Career Pipeline：多岗位、阶段推进、JD 与简历关联、面试/日程绑定、历史与归档恢复。
- Knowledge Base：本地资料导入、文件类型识别、层级目录、标签、关键词搜索、预览、Markdown 编辑和真实面经格式解析。
- Resume System：基础资产与岗位版本、模板选择、版本时间线、修改摘要、差异标记、归档回收站、求职目标绑定。
- Interview Engine：面试主页、最近记录、三种独立配置页、题量边界、可追溯来源、面试房间、暂停/恢复、提交回答和复盘报告。
- Schedule：现实面试、笔试和跟进提醒，支持按求职计划关联并在首页显示近期安排。
- 本地 AI 配置：OpenAI 兼容协议、Anthropic Messages、Google Gemini，以及 DeepSeek、智谱 GLM、通义千问、Moonshot 等常用兼容服务预设。
- Desktop：Electron 主进程负责窗口、回环端口、本地 Spring Boot 生命周期、H2 工作区、备份和模型密钥的受控存储。

## 用户可以怎样使用

1. 在设置中添加一个模型服务（也可以先不配置 AI，继续使用本地资料和简历能力）。
2. 创建一个求职计划，录入公司、岗位、JD 和阶段，再关联需要使用的简历版本。
3. 把 Markdown、PDF、TXT 或真实面经资料导入知识库，按目录和标签整理。
4. 从 Workspace 查看下一场现实面试和今天的主行动；从面试主页选择训练记录或开始新的练习。
5. 完成面试后打开复盘，查看当时的上下文、核心问题和下一步行动，再回到简历或知识库继续准备。

## 验证结果

- 前端：79 个测试文件、441 个测试通过；生产构建通过。
- 后端：580 个测试通过，0 失败、0 错误、0 跳过。
- 路由 smoke check：Workspace、求职计划、知识库、简历库、编辑台、能力证据、面试、日程和设置均能加载，控制台错误为 0。
- 完整验证细节见 [V2.0 发布前验证报告](v2.0-test-report.md)。

## 已知限制

- 测试环境不会调用真实外部模型；实际回答质量取决于用户配置的服务、模型和配额。
- Electron 的 macOS 与 Windows 产物需要分别在对应系统构建；正式分发仍需补齐代码签名、公证和更新策略。
- 前端构建仍有 bundle 体积和依赖注释提示，后续会作为性能维护任务处理。
- 语音面试、日历同步、Skill/MCP、Career Agent 和投递辅助不属于本版本的完成范围。

## 隐私说明

简历、联系方式、知识原文、面试回答和本地数据库默认保存在用户设备。模型密钥只通过桌面端受控存储进入本地后端运行期，不写入普通日志、面试快照或导出文件。AI 不会自动编造用户经历，也不会静默覆盖用户保存的简历内容。
