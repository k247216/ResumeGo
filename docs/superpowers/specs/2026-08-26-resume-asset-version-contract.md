# Resume Asset Version Contract

## 目标

冻结基础简历、岗位简历和求职目标之间的关系，确保每次保存都能被追溯、不会静默覆盖，也不会因为绑定求职目标而意外复制资产。

## 资产模型

### 基础简历（`GENERAL`）

- 保存长期可复用的个人经历、项目、教育和技能事实。
- 版本时间轴独立递增：`V1 → V2 → V3`。
- 不因为绑定求职目标而改变内容或版本号。
- 可以作为多个求职目标的临时关联来源。

### 求职目标（Career Pipeline）

- 记录公司、岗位、JD、当前阶段、面试记录和日程。
- 不承载简历正文，也不自动创建简历副本。
- 一个岗位版本最多绑定一个求职目标。

### 岗位简历（`JOB_EXPRESSION`）

- 是基于某个基础简历版本创建的独立职业表达资产。
- 创建时记录 `forkedFromVersionId`，并可绑定一个求职目标。
- 拥有自己的版本时间轴，从 `V1` 开始：`岗位简历 V1 → V2 → V3`。
- 基础简历后续修改不会污染岗位简历；岗位简历后续修改也不会回写基础简历。

## 绑定规则

1. 新建求职目标时不自动创建岗位简历。
2. 没有岗位定制需求时，允许目标暂时绑定某个基础简历版本。
3. 需要定制时，由用户明确点击“基于基础简历创建岗位版本”，选择来源版本并确认标题。
4. 岗位版本创建成功后才自动绑定到该目标；绑定操作可通过卡片式面板更换或解除。
5. 已绑定状态不展示原始下拉框，只展示公司、岗位、阶段和当前简历版本。

## 版本说明

- 每次保存新版本都允许用户填写 `changeSummary`。
- 版本说明显示在版本时间轴和版本检查器中。
- 说明为空时只展示时间和真实内容差异，不生成虚构说明。
- 历史版本只读；编辑必须创建新的版本。

## 预览交互

- 简历纸张采用工作区可读比例渲染（当前实现为 70%），不在界面显示容易误导的百分比控件。
- 滚轮和滚动条只作用于正文预览容器。
- 更新摘要与颜色图例位于正文左侧，图例固定在该栏底部。
- 中间分隔线贯穿更新栏和正文预览；右侧检查器不参与正文滚动。

## 非目标

- 本阶段不新增自动投递、评分、岗位匹配或云端同步。
- 收藏是独立的资产级本地元数据；删除只进入可恢复的回收站，不改变版本正文。
