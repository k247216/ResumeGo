# 面试模式页面与复盘工作区设计规范

> 状态：已获用户确认，进入实现
>
> 日期：2026-08-26

## 1. 目标

将面试主页之后的流程从“一个配置器承载三种模式”收敛为三个互相隔离的模式准备页面，并将复盘改造成独立的白色桌面工作区。首页只负责练习记录与下一步行动；准备页负责模式和来源配置；房间负责专注回答；复盘负责把一次练习转成下一步行动。

## 2. 页面状态与导航

保留现有 `/interview` 路由和 `view=home|setup|room|review` 查询协议，以免历史链接失效。`setup` 增加明确的模式上下文：

```text
home
  ├─ setup + ROLE_BASED（自由面试入口）
  ├─ setup + KNOWLEDGE_TRAINING（知识训练入口）
  └─ setup + EXPERIENCE_SIMULATION（真题演练入口）
             ↓ 开始后锁定上下文
          room
             ↓ 完成或从历史进入
          review
```

首页的三个入口直接进入各自的准备页，不再经过一个可切换的合集页。准备页只渲染当前模式的配置组件；模式在路由中明确记录，返回主页后再选择另一种模式。面试开始后禁止在房间内改模式或来源。

## 3. 三种准备页面

### 3.1 自由面试（`ROLE_BASED`）

必须由用户明确选择：

- 一个 Career Pipeline；
- 一个 Resume Version；
- 至少一个面试官及顺序；
- 可选考察方向、题量和补充说明。

岗位和简历是两个独立选择。岗位切换不自动切换简历，简历切换也不自动修改岗位。开始后快照保存 ID、用户可见名称、版本号、面试官顺序和配置版本。

### 3.2 知识训练（`KNOWLEDGE_TRAINING`）

必须先从当前用户的 Knowledge Base 选择至少一份已处理完成的资料，可多选；再填写可选的知识重点、难度和题量。该页面不要求岗位、简历或面试官。

问题和评价必须携带资料来源引用；资料中没有依据时显示“当前资料中未找到依据”，不能用模型常识冒充资料结论。开始后快照保存资料 ID、标题、选择顺序、关注重点和输出 schema 版本。

### 3.3 真题演练（`EXPERIENCE_SIMULATION`）

必须选择当前用户创建或导入的真实面经题集；题集为空、已归档或没有可用原题时禁止开始。页面可设置抽题数量和追问强度，不再要求选择面试官角色。

面经属于 Knowledge Base 的“真实面经题集”资产类型，而不是普通技术笔记。用户在知识库中手动录入或导入面经，系统以 `InterviewQuestionSet` 保存原题、来源和归属；真题演练只读取这类题集，知识库为空时保持真实空状态，不渲染演示题集。

原始面经题必须保留原文和来源标签。AI 追问单独标记为 `AI_FOLLOW_UP`，不得显示为真实题目；用户手动录入与导入题集分别标记来源。

## 4. 统一白色桌面视觉

- 页面背景为纯白或暖白，主文字炭黑，辅助文字中灰；深色主题沿用同一层级映射，不新增大面积色块。
- 使用宽阔画布、细分隔线、明确对齐和留白，不使用卡片套卡片、巨型标题或营销横幅。
- 模式只用小型图标、标签和一条语义色提示区分；颜色不承担状态真值。
- 每个准备页顶部显示当前模式与来源信号，中部为该模式的上下文配置，底部为唯一开始按钮和来源校验提示；不在准备页展示跨模式切换器。
- 复盘页主工作区占视觉主体，右侧为窄栏辅助信息，不把趋势图或分数墙做成中心内容。

## 5. 复盘工作区

复盘由 `sessionId` 定位，读取开始时的上下文快照，不用当前岗位、简历或知识标题覆盖历史。

主区按以下顺序展示：

1. 模式、来源和完成时间；
2. 核心问题（一条）；
3. 回答证据（可定位到问题）；
4. 下一步行动（可再次练习）；
5. 可展开的逐题时间线。

右侧窄栏展示：

- 本次上下文摘要；
- 真实评分维度或诚实空状态；
- 返回面试主页；
- 用快照重新开始一次新练习。

无总结、无评分或题目加载失败时分别显示明确空态，不生成占位分数。再次练习创建新计划/会话，不修改历史复盘。

## 6. 状态与数据边界

- `Pipeline`、`ResumeVersion`、`KnowledgeDocument`、`InterviewQuestionSet` 是独立对象，只通过显式 ID 关联。
- 计划创建后 `mode` 与 `startContextSnapshot` 不可修改。
- AI 只能生成问题、追问、评价和总结，不能改变面试状态、岗位阶段、简历正文或题目来源。
- 历史面试回答、来源和评价必须可回放；源资产后续修改不改变历史快照。
- API Key、完整简历正文、知识正文和题目全文不进入普通日志。

## 7. 验收标准

- 从首页点击任一练习入口后，直接进入对应的独立配置页；不会同时看到其他模式的字段，也不会出现一个额外的模式合集页。
- 知识训练没有资料不能开始；真题演练没有真实面经题集不能开始。
- 路由刷新后仍能回到正确模式，离开准备页再进入另一种模式时不会串带不兼容的岗位、简历、资料或题集 ID。
- 面试房间内模式和来源不可修改；完成后自动进入复盘。
- 历史记录进入复盘时，显示开始快照而不是当前对象名称。
- 复盘页面全程白色桌面风格，主区、逐题时间线和窄右栏对齐；无真实数据不显示假趋势。
- `npm run build`、面试模式专项测试和核心浏览器尺寸检查通过。
