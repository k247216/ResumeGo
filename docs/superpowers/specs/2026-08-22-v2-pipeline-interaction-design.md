# V2 Career Pipeline 页面交互契约

Status: Approved for F1 implementation

Route: `/targets`

Desktop minimum: `1080 × 720`

## 1. 页面职责

Pipeline 页面管理真实岗位机会，回答：有哪些机会、当前处于哪个阶段、使用什么岗位材料、发生过哪些阶段变化，以及关联了哪些现实日程和模拟面试。

它不是 Workspace，不负责“今天做什么”；不是简历编辑台、完整日历或完整模拟面试；也不展示成长分数、AI 状态大卡、完整简历预览或知识库内容。

## 2. 信息结构

采用桌面双栏工作区：

- 左栏 `248–280px`：Pipeline 列表、状态筛选和新建入口。
- 右栏：当前 Pipeline 的身份、阶段轨道、材料、关联事项和历史入口。
- 页面使用现有 DesktopShell；不增加第二套全局导航，不修改工作台布局。

左栏先显示 `ACTIVE/PAUSED`，后显示 `ARCHIVED/CLOSED`。每项只展示公司、岗位、当前阶段和生命周期，不塞入简历缩略图或统计卡。

右栏优先级：

1. 公司与岗位身份；
2. 当前阶段和可执行的阶段推进；
3. JD、简历版本和关联修复；
4. 日程与模拟面试摘要；
5. 按需展开的阶段历史。

## 3. 关键流程

### 创建与选择

- 新建表单包含 Pipeline 名称、公司、岗位，可选 JD 和简历版本。
- 初始阶段不自定义时发送空数组，使用后端默认阶段；创建后可进入阶段管理。
- `/targets?pipelineId={id}` 支持预选；无效 id 回退 store 选择，不显示伪数据。
- 切换 Pipeline 只改变 Pipeline 选择和 route query，不自动切换简历库、日程或模拟面试上下文。

### 身份与材料

- “编辑信息”使用一个对话框全量提交五个字段。
- JD 和简历版本允许明确选择“未关联”；保存时必须显式发送 `null`。
- 简历版本选择先选简历，再选该简历的真实版本；不得默认把“当前简历”写成某个虚构版本。
- 关联 id 已失效时展示“关联不可用”，保留修复入口，不猜测替代资产。

### 阶段

- 轨道按照服务端 position 展示；CURRENT 是视觉重点，COMPLETED/SKIPPED 弱化，PENDING 可推进。
- 推进前二次确认并允许填写可空说明；不能回退到已完成阶段。
- 阶段管理支持新增、重命名、使用上移/下移排序；F1 不提供删除阶段。
- 归档/恢复位于身份区次级操作；ACTIVE/PAUSED 可归档，ARCHIVED 可恢复，CLOSED 只如实展示，前端不制造后端不存在的状态命令。

### 关联与历史

- 日程和模拟面试分别显示真实关联数量及可解析名称；无法解析的 id 显示“关联不可用”。
- 管理关联使用轻量对话框，可逐项关联或解除；专业内容仍在日程/模拟面试页面完成。
- 阶段历史从“查看阶段历史”打开右侧抽屉时加载。历史按服务端顺序展示，不在前端重排、编辑或删除。

## 4. 状态与错误

- 首次加载：右栏骨架或安静加载态，不闪现旧 Job Project。
- 空列表：单一空态，主按钮“创建第一条求职管线”。
- Pipeline 主列表失败：显示错误和“重试”，保留已有数据。
- 辅助资产失败：只影响对应材料/关联区域，不让整页不可用。
- mutation 失败：对话框保持打开并显示 store 错误；成功后再关闭。
- 归档当前 Pipeline 后继续保持选中，用户可以查看和恢复。

## 5. 响应式与视觉

- `≥1280px`：左栏 280px，右栏内容最大宽度约 980px，材料与关联区域可两列。
- `1080–1279px`：左栏 248px，右栏卡片单列或紧凑两列，不出现水平页面滚动。
- 高度不足时左右栏各自滚动；DesktopShell 工具栏保持固定。
- 使用现有黑白日夜主题与少量状态色；浅边界用于分组，不使用密集卡片墙、巨型数字和强光晕。
- 所有主要操作支持键盘焦点；对话框有标题、关闭、取消和明确提交按钮。

## 6. 组件边界

- `PipelineView`：路由、store 加载、辅助资产加载与对话框编排。
- `PipelineListRail`：列表和选择，不读取 Resume/Schedule/Interview store。
- `PipelineIdentityPanel`：身份、生命周期、归档恢复和编辑入口。
- `PipelineStageTrack`：阶段展示与推进入口。
- `PipelineMaterialsPanel`：JD/简历版本摘要和修复入口。
- `PipelineRelationsPanel`：日程/模拟面试关联摘要与管理入口。
- Dialog/Drawer：创建、编辑、阶段管理、推进确认、关联管理、历史。

组件只通过 props/emits 与 store/API 结果交互，不复制 Pipeline 领域状态。

## 7. 验收场景

必须覆盖：加载、空态、失败重试、创建并选择第二条 Pipeline、query 预选、编辑身份与显式解除关联、失效关联修复、推进阶段、新增/重命名/排序、历史抽屉、归档恢复、关联/解除日程和面试计划、1080px 布局、浅色/深色、键盘可达。
