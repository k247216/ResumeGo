# ResumeGo 工作台响应式与主题审查

## 审查范围

- 页面：首页工作台
- 目标：检查设计稿一致性、不同桌面窗口尺寸下的完整展示，以及日间／夜间主题
- 证据：本目录 4 张本轮新截图

## 步骤与状态

1. `01-light-1487x1058.png`：1487 × 1058 日间模式。整体结构可用，但工具栏和设计稿比例仍有偏差。
2. `02-light-1280x800.png`：1280 × 800 日间模式。页面总高度 1054 px，底部简历和模拟面试组件不能在一屏完整显示。
3. `03-light-1024x768.png`：1024 × 768 日间模式。仍保持双栏，但页面总高度 1064 px，阶段区换行后进一步占用纵向空间。
4. `04-dark-1280x800.png`：1280 × 800 夜间模式。标题对比度严重不足，卡片间出现白色背景缝隙，主题不完整。

## 主要发现

### P1｜夜间模式存在全局样式污染

`frontend/src/style.css` 中旧页面的全局 `.workbench-grid`、`.panel-heading` 和 `.panel-heading h2` 与新工作台组件同名。新组件没有覆盖旧规则中的白色背景、overflow、边框和固定深色标题，因此夜间模式出现白色网格缝隙与近乎不可见的标题。

### P1｜响应式只考虑宽度，没有考虑窗口高度

当前断点仅使用 `max-width`。1487 × 1058 时页面高度刚好为 1058 px；切换到常见的 1280 × 800 后，组件仍保留 174 px 头部、338/366 px 主卡片和固定间距，页面高度达到 1054 px。1024 × 768 时同样达到 1064 px。

### P2｜工具栏比例偏重

当前工具栏宽 72 px、单个入口 50 × 50 px，且与主体之间的视觉重量较大。设计方向更适合 60–64 px 工具栏和 42–44 px 的选中入口，同时保留足够点击区域。

### P2｜1024 px 宽度的阶段区重排增加高度

1120 px 以下，阶段轨道被强制换到第二行，但主体仍维持大型卡片尺寸；这不是有效的紧凑桌面布局，只是增加了一行。

## 可见的可访问性风险

- 夜间模式主标题与卡片标题对比度不足。
- 主题切换后部分背景仍为纯白，容易造成明显眩光和视觉割裂。
- 中等高度窗口必须滚动才能到达主要简历操作，降低核心操作的可发现性。

截图不能证明完整键盘顺序、屏幕阅读器表达或 WCAG 合规；这些仍需单独测试。

## 建议修正方案

1. 将首页组件类名改为工作台专属命名，或完整重置被旧全局 CSS 污染的属性。
2. 保留黑白主风格和绿色状态色，但统一使用主题变量控制画布、卡片、文字、分隔线和按钮。
3. 工具栏缩到 62 px，入口缩到 44 px；内容区保持清晰间距。
4. 增加高度断点：在 900 px 以下压缩头部、目标条、卡片高度和纵向间距；1280 × 800 与 1024 × 768 均保持核心首页在一屏内。
5. 900 px 以下再切换为单列滚动，而不是在普通桌面尺寸过早堆叠。
